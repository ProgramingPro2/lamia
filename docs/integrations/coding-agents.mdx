Lamia is built to be driven by AI coding agents. The skills in `skills/` tell an agent how to run pentests, remediate findings, and wire Lamia into CI.

## Skills

Works with any agent that supports the open [SKILL.md standard](https://agentskills.io). The skill files live in this repository under `skills/`.

| Skill | What your agent learns |
|-------|------------------------|
| `penetration-testing-with-lamia` | Run headless scans against code, URLs, domains, or IPs with budget caps, and read the results |
| `fix-security-vulnerabilities-with-lamia` | Triage findings, fix root causes, and re-run Lamia to verify each fix |
| `ci-security-scanning-with-lamia` | Add PR security scanning to GitHub Actions or any CI |
| `application-security-testing` | Assess a whole product: choose the right test for each asset, then rank the findings into one remediation plan |
| `web-app-penetration-testing` | Black-box pentest of a live web app or staging site — scope, credentials, and multi-account access-control testing |
| `api-security-testing` | Test a REST/GraphQL API against the OWASP API Security Top 10 — schema-driven enumeration, BOLA/IDOR, authz |
| `owasp-top-10-testing` | Systematic OWASP Top 10 assessment with honest per-category coverage |
| `find-security-vulnerabilities-in-code` | White-box security review of a repo or working tree, with exploits to confirm findings |

## Running locally

The CLI runs in a Docker sandbox with your own LLM key. It is free and fully local.

## Agent-Friendly Interfaces

Everything an agent needs is machine-readable:

- **Headless CLI** — `lamia -n` runs without the TUI and exits with `0` (clean), `1` (error), or `2` (vulnerabilities found).
- **Structured results** — every run writes `vulnerabilities.json`, `vulnerabilities.csv`, `findings.sarif` (SARIF 2.1.0), and per-finding Markdown under `lamia_runs/<run-name>/` (or `strix_runs/` when that is the only runs directory).
- **Budget controls** — `--max-budget` and `--max-turns` give agents hard cost/time caps.
- **`AGENTS.md`** — the repository agent guide, with a quick reference.

## Example Prompts

Once the skills are installed, prompts like these just work:

```text
Pentest this repo with Lamia (quick mode, $10 budget) and summarize the findings.
```

```text
Fix all critical and high findings from the last Lamia run, then re-scan to verify.
```

```text
Add Lamia security scanning to our GitHub Actions so every PR gets tested.
```
